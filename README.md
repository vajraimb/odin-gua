# odin-gua

用 Odin 写的易经起卦 MCP 服务器：agent 里随时起卦、按规则取原文、自动记录，并像评估模型一样复盘。

> 仅供娱乐与自我反思，不构成任何决策（含投资）依据。

## 设计原则

- **排卦归程序，解卦归模型。** 随机数、互错综变、取哪条爻辞都由代码确定并可复现；模型只负责联系问题去解释。
- **用户零操作。** 用户只提问；起卦、记录、复盘提醒都自动完成。
- **复盘即评估。** 每一卦都是一次“预测”，事后对照结果、做安慰剂对照与评委打分。

## 为什么用 Odin

- 单个无依赖二进制，stdio 启动毫秒级，不需要 uv / npx。
- 卦辞、Unicode、英文名、文王表用 `#load` 编进二进制，离线可用。
- 数据正确性用 `#assert` 和启动自检保证（64 卦齐全、文王序“非综即错”成对、Unicode 映射）。
- `bit_set[Yao; u8]`：一爻一位，错卦 `~g`、变卦 `g ~ moving`。

## 数据

- 卦符：U+4DC0–U+4DFF，按文王序排列，`0x4DC0 + 序号 - 1`。
- 英文名：Unicode 字符名（如 `HEXAGRAM FOR THE CREATIVE HEAVEN`）。
- 八卦：U+2630–U+2637；单爻：⚊ U+268A、⚋ U+268B。
- 卦辞爻辞：待逐条核对公开文本；英文译文计划用 Legge (1882，公有领域)。

## 工具（草案）

| 工具 | 作用 |
|---|---|
| `cast` | 起卦（三钱法/大衍法），必须带 `question`；返回卦象、应读原文、到期复盘清单 |
| `lookup` | 按序号、中文名、英文名、Unicode 符号、六位二进制查卦 |
| `relations` | 互、错、综、变 |
| `annotate` | 写回模型解读：倾向、置信度、复盘日期 |
| `review` | 记录事后结果 |
| `report` | 命中率、Brier 校准、安慰剂对照、评委点评 |

资源：`hexagram://1` … `hexagram://64`。

## 规则

- **取辞**：按朱熹《易学启蒙》常用规则，由动爻数决定读哪段原文。
- **不再三**：同一问题短时间内重复起卦标记为“渎”，不计入统计（防止挑结果）。
- **安慰剂对照**：复盘时盲解一个随机卦，与本卦解读比较贴合度。

## 路线

1. `cast` / `lookup` / `relations` + 自动日志 + Unicode/英文名
2. 卦辞爻辞原文入库（逐条核对）+ `reading` 规则
3. `annotate`、复盘提醒、防重摇
4. `review` / `report`、安慰剂对照、评委打分
